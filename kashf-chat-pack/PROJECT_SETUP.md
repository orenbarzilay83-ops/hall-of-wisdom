# הגדרת פרויקט ChatGPT — גורל החול (מערכת ייעוץ והכוונה)

שם הפרויקט: **גורל החול (מערכת ייעוץ והכוונה)**. זהו פרויקט עבודה מקצועי של אורן משה לשיטת כשף אל־אסראר, עם מקור משלים נפרד מאל־קול אל־ג׳אמיע.

## הוראות ומקורות

1. פתח את הפרויקט בשם שלמעלה (או צור אותו אם טרם נוצר). הכנס את **כל** תוכן `PROJECT_INSTRUCTIONS.md` לשדה הוראות הפרויקט.
2. העלה למקורות הפרויקט את `CANONICAL_METHODS.json`, `QUESTION_ROUTES.json`, `SOURCE_INDEX.json`, `QAWL_SPIRITUAL_METHOD.json`, `SPIRITUAL_SCOPE.md`, `PROJECT_WORKFLOWS.md` ו־`GOLDEN_CASES.json`. אלה קובצי ידע; אין ללמוד כללי מקור מקבצי `runtime/`.
3. שמור גם את `kashf-chat-pack.zip` כמקור עבודה לחישוב, או צרף אותו לשיחת Work שבה מריצים קריאה. הקובץ מכיל `run.mjs`, `SELF_TEST.mjs` ותלויות runtime. עצם ההעלאה שלו אינה מפעילה קוד.
4. פתח שיחת Work בפרויקט. בקש לחלץ את ה־ZIP, להריץ `node SELF_TEST.mjs`, ולדווח את הפלט. אם אין גישת shell/Node לארכיון, המשך בשיחת לימוד מקור בלי להציג פסק מחושב.
5. לאחר PASS, בדוק שיחת מקור, קריאה קנונית, קריאה רוחנית ומסלול חסום לפי `PROJECT_WORKFLOWS.md` §4. תעד סטייה במפורש לפני שימוש עם לקוחות.

הפרויקט אינו מחליף את בדיקות המקור והקוד. אין לטעון שהוגדר או שנבדק חי עד שמצבו נראה בחשבון ChatGPT שבו ישמש אורן משה.
