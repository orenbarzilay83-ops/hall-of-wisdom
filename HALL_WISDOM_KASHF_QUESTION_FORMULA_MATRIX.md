## Cross-cutting notes

- **General-purpose (non-topic-bound) techniques identified**, distinct
  from any single row above: the "decision-oracle" pattern (row 4, and
  recurring in rows 16 & 20); the "sub-board recast" pattern (rows 16 &
  19); the "מעגל" (circle/dignity-based counting) technique (row 13,
  dependent on Gate-2's essential-dignities table). These are
  **infrastructure patterns reusable across many topics**, not
  single-topic formulas — see the Sub-Engine Inventory deliverable.
- **Witness systems (A-F, per the Witness Systems Map)** are almost never
  invoked BY NAME within Gate 6's topic chapters — the recurring phrase
  "לפי כוח העדים" / "והאל יודע" appears generically, without specifying
  *which* witness system. This matches the earlier audit's finding for
  spiritualDiagnostics specifically, and now appears to hold across the
  whole book: **the book does not explicitly wire any of the 6 witness
  systems into any single topic-formula by name**, except the basic
  house-13/14/15 testimony scheme (System C) which is structurally always
  present via houses 13-15's board role.
- **Dhamir is confirmed topic-independent** (per Gate 4's own framing,
  "עצמאי מהנושא שנבחר") — none of the 21 rows above showed a topic-specific
  dhamir invocation, consistent with existing code's design.
- **No topicId or Rule ID above is final** — all are working labels for
  this mapping exercise only, explicitly flagged `[provisional]`.
